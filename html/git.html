Git

  • git init: Инициализирует новый Git-репозиторий в текущем каталоге.
  • git clone : Клонирует удаленный репозиторий в локальную директорию.
  • git add <файл>: Добавляет изменения файла в "индекс" (staging area) для последующего коммитa.
  • git status: Показывает состояние рабочего каталога и индекса: какие файлы изменены, какие добавлены в индекс, а какие отслеживаются.
  • git commit -m "Сообщение": Совершает коммит, сохраняя все добавленные в индекс изменения в историю репозитория.
  • git log: Показывает историю коммитов, включая сообщения и хеши.
  • git diff: Показывает различия между различными версиями проекта, например, между рабочим каталогом и индексом, или между двумя коммитами.
  • git rm <файл>: Удаляет файл из рабочего каталога и из индекса.
  • git reset: Используется для отмены изменений, как в индексе, так и в рабочем каталоге, или для возврата к определенному коммиту.
  • git stash: Временно сохраняет несохраненные изменения, чтобы можно было переключиться на другую задач
